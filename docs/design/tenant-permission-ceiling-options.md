# 租户权限上限候选项

租户权限上限不能直接使用全局权限树：其中包含平台范围权限，保存时会被拒绝。候选查询和写入校验都以启用的租户范围主资源/动作为准。已有授权即使后来停用仍在读取结果中返回，并标注为不可再分配，方便管理员清理。

| 关注点 | 决定与理由 |
| --- | --- |
| 契约 | `POST /api/v1/platform/tenant-authorization/permissions/page`；输入 `page`、`page_size`、`keyword`，输出 `{items,page,page_size,total}`。按权限标识和 ID 稳定排序，关键词对标识和名称做不区分大小写模糊匹配，最大页长沿用共享分页的 200。无 `IN` 和时间范围：仅供有界远程候选搜索。`permissions/get` 为已有授权增加 `assignable`。错误使用全局错误码。 |
| 认证与授权 | JWT，`tenant:grant` 平台权限；服务端保存时重新校验，候选结果不构成授权凭据。 |
| 操作日志 / 安全日志 | 两个读取接口均不记录；授权变更仍由既有写入接口记录操作和安全事件。 |
| 缓存 | 不缓存；权限、资源和动作状态变化应立即生效。 |
| 分布式锁 / 乐观锁 | 只读无锁；写入沿用租户级最小锁和 `tenant_id`、`version` 乐观锁。 |
| 审计 | 无新表；查询过滤所有关联对象的状态和逻辑删除标记，写入沿用审计触发器。 |
| 展示 | 返回权限 ID、稳定标识、名称、资源和动作；旧授权明确显示为不可再分配。无日期或敏感值。 |
| 测试 | 单测覆盖租户范围分页/关键词、平台主体限制、旧授权状态和参数错误；前端单测覆盖远程分页、保留已选项及取消旧授权。Testcontainers 集成测试留在本服务 CI。 |
| 共享能力 / 字典 | 复用共享分页、响应、授权拦截和选择组件；授权候选不暴露为公共匿名字典。 |

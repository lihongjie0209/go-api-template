# 平台授权的权限候选项

`permissions.resource` 只是权限树的主资源展示字段，不是授权判定依据。平台授权按 `permission_resource_actions` 中至少一条有效的平台范围动作判断。候选接口与授权写入使用同一规则，避免前端漏掉可授权的多动作权限。

| 关注点 | 决定与理由 |
| --- | --- |
| 契约 | `POST /api/v1/platform/permission-grants/permissions/page`；输入 `page`、`page_size`、`keyword`、可选 `ids`（最多 200 个 UUID，与关键词取交集），输出统一 envelope 内的 `{items,page,page_size,total}`。关键词对权限标识和名称不区分大小写模糊匹配；固定按标识、ID 排序；默认 1/20，最大 200，关键词最多 256 字符。`ids` 用于远程多选回填及剔除已失效选择，空数组表示不限制；无时间范围字段。参数错误使用全局请求错误码。 |
| 认证与授权 | JWT，`permission.definition:list`，平台范围；不接收租户参数，也不暴露租户权限候选。服务端操作授权仍在写入接口重检。 |
| 操作日志 / 安全日志 | 只读候选查询不记录，两类日志均无；实际授权写入由既有接口记录。 |
| 缓存 | 不缓存；有效动作和权限状态变化后必须即时反映，数据库为权威来源。 |
| 分布式锁 / 乐观锁 | 只读接口均不使用；写入继续使用既有事务与版本号。 |
| 审计 | 不写表；依赖现有权限、动作及关联表的审计字段和逻辑删除过滤。 |
| 展示 | 返回稳定的权限 ID、标识和名称，前端显示“标识 · 名称”；无时间、敏感字段或关联裸 ID 展示问题。 |
| 测试 | 单测覆盖分页、关键词、ID 数量与 UUID 校验、SQL 关联动作范围和状态过滤、数据库错误及空结果；前端单测覆盖候选映射、远程搜索、有效选中项回填与失效项清理。集成测试由 CI 的本服务 Testcontainers 套件执行。 |
| 共享能力 / 字典 | 复用共享分页、响应和授权拦截；安全敏感候选不做公共匿名字典。 |
